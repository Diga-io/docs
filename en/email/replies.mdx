# Replies

The agent always replies **in the same thread and to everyone** on the email. You decide what happens to each reply it writes.

## Send mode

| Mode | What it does |
|---|---|
| **Draft** (default) | The reply stays in Outlook's Drafts folder. You review it, change it if you want, and send it. |
| **Automatic send** | The agent sends the reply itself. |

### In draft mode

- If the customer writes again before you send the draft, the agent **replaces** it with a new one that answers everything pending.
- If you have **edited** the draft, the agent leaves it alone and writes no other.
- If you **send** the draft from Outlook, it counts as the agent's reply.
- If you **delete** it, that reply is discarded.

### Delay before sending

With automatic send you can set a delay in minutes. The reply waits that long in Drafts and is then sent on its own. While it waits you can read it and change it.

<Warning>
If you edit a reply while it waits, **it is no longer sent on its own**: it stays as a draft for you to send when you are done.
</Warning>

A waiting reply is not sent either if a person takes the thread, if you switch the mailbox to draft mode, or if the customer writes again (the agent then writes a new reply).

## Signature

Each mailbox has its signature, added at the end of every reply. You can set it in two ways:

- **Write it in Diga**, with formatting, links and your logo.
- **Detect it**: Diga reads the last emails you sent from that mailbox, finds the block they end with and proposes it. Nothing is saved until you confirm, and you can edit it first.

Keep in mind:

- **The logo travels inside the email**, as in Outlook, so the customer sees it without downloading images. It accepts PNG, JPEG or GIF up to 1 MB. If the detected signature has a larger image or one in another format, the proposal tells you it was left out.
- **Detection needs at least two sent emails that end the same way.** If there are none, it proposes nothing rather than inventing a signature.
- **If you always sign off the same way** ("Best regards,"), the sign-off may come in the proposal with the signature. You can keep it or remove it.
- **The agent reads the signature** and does not repeat what it already says: if the signature includes the sign-off and your name, the reply ends with its last sentence. With no signature, the agent ends with a short sign-off and the name of the mailbox's owner.
- For safety, scripts and forms are removed from the signature.

## Artificial intelligence notice

Replies the agent sends on its own end with a notice that they were written by an artificial intelligence, in the language of the reply. Drafts carry no notice, because a person reviews and sends them. You can turn the notice off per mailbox.

## When a conversation closes

A thread with no email for 72 hours is considered finished and its [post-call workflows](/en/build/flows/post-call-flows) run. If the customer replies later in the same thread, a new conversation opens and keeps the history. With [follow-ups](/en/email/follow-ups) on, the conversation stays open while the agent waits to write a reminder.
